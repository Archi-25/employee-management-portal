  • Prefer interpolation; reach for [innerHTML] only when markup is required.
  • Never concatenate user input into a template — avoid runtime template compilation.
  • Treat bypassSecurityTrust* as a code-review trigger, one call at a time.
  • Allowlist hosts before trusting any resource URL (iframe, script, object).
  • Never touch ElementRef.nativeElement.innerHTML; use Renderer2.
  • Sanitise on the server too — client-side sanitisation is defence in depth, not the boundary.
  • Ship a Content-Security-Policy and Angular's ngCspNonce for inline styles.
