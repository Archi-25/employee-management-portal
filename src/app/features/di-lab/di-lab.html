Two panels, two distinct instance ids — a component-level provider creates one instance per component instance, unlike providedIn: 'root'.

The lookup stops at the view boundary instead of falling through to the root injector, which is exactly what makes @Host() useful for directives that are only valid inside a specific parent — formControlName works this way.

The subtlety: @Host() can see the host component's viewProviders but not its providers. Both are on the same element, yet providers sits one step further out so that projected content can reach it too — and that extra step is past where @Host() stops.
